# Self-hosted headline lettering

Great Vibes Regular by Robert E. Leuschke (TypeSETit), licensed under the SIL Open Font License 1.1. The unchanged license is included as `GreatVibes-OFL.txt`.

`GreatVibes-Regular-latin.woff2` is Google Fonts’ Latin web subset, downloaded on October 11, 2026 from its official font CDN:

https://fonts.gstatic.com/s/greatvibes/v21/RWmMoKWR9v4ksMfaWd_JN9XFiaQoDmlr.woff2

The source font and license are maintained in the official Google Fonts repository:

https://github.com/google/fonts/tree/main/ofl/greatvibes

The web font was obtained from the Latin block of:

https://fonts.googleapis.com/css2?family=Great+Vibes&display=swap

The face has one normal weight (400). The changing headline word uses a small additional CSS shear to distinguish it; the font binary is unmodified. All runtime loading should use the local asset, with no request to Google Fonts.
